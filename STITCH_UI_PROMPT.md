# Stitch Vision-Driven Product Prompt
# Application: LTrack — Collaborative Engineering Learning & Assessment Platform

> **Instructions for Stitch:** Copy and paste the prompt below into Google Stitch (or any AI UI design tool) to generate UI/UX designs based purely on the application's vision, collaborative learning philosophy, and user workflows.

---

```markdown
Design a comprehensive web application interface for "LTrack" — a collaborative software engineering learning, verified progress tracking, and peer mentorship platform designed for engineering teams and cohort bootcamps.

### 🌟 Core Vision & Philosophy:
LTrack is built on three foundational principles:
1. **Evidence-Based Engineering Progress**: Learning is not measured by passive video watching or self-checks alone. Real mastery is verified through evaluated GitHub Pull Requests, conventional git commit hygiene, and structured code reviews.
2. **Collaborative Peer Growth ("No Teammate Left Behind")**: Learning engineering is hard alone. When a learner struggles or falls below average on a concept, the community rallies around them. Teammates can transparently see who is stuck, offer live pair-programming sessions, share code snippets, and solve bugs together.
3. **High-Touch Coordinator Diagnostics & Mentorship**: Program coordinators and engineering leads have real-time visibility into every learner's journey. Instead of generic dashboards, coordinators can inspect individual struggling areas (e.g. low-confidence check-ins, missing PRs), assign peer mentors, and dispatch personalized 1-on-1 action plans.

---

### 👥 User Personas & Strict Portal Segregation:

#### 1. The Learner (Member) Portal:
- **Primary Goal**: Follow the structured 13-phase backend & AI curriculum, maintain daily study streaks, submit GitHub PRs for evaluation, view their own comprehensive progress analytics, and collaborate with peers in real-time pairing sessions.
- **Key Needs**: Clear lesson roadmap, distraction-free workspace, instant feedback on git commit conventions, on-demand peer help, and deep personal learning analytics.

#### 2. The Coordinator / Admin Portal:
- **Primary Goal**: Manage the entire engineering curriculum (full CRUD over topics, phases, and checklist concepts), publish coding assignments with criteria, grade peer PR submissions across standardized criteria, detect at-risk students automatically, and dispatch tailored guidance plans.
- **Key Needs**: Executive group KPIs, full management controls (CRUD), diagnostic drill-down per student, and rapid intervention tools.

---

### 🗺️ The 13-Phase Engineering Curriculum Scope:
The platform guides learners through an end-to-end engineering syllabus:
- Phase 1: Python Advanced OOP & Data Structures
- Phase 2: HTTP Fundamentals & Web Architecture
- Phase 3: REST API Design & Client-Server Contracts
- Phase 4: FastAPI Architecture & Dependency Injection
- Phase 5: PostgreSQL & Async SQLAlchemy ORM
- Phase 6: Authentication & Security (OAuth2 / JWT / RBAC)
- Phase 7: Machine Learning API Deployment
- Phase 8: LLM Integration & Prompt Engineering
- Phase 9: Retrieval-Augmented Generation (RAG & Vector DBs)
- Phase 10: Model Context Protocol (MCP Server Architecture)
- Phase 11: Autonomous Agentic AI Systems
- Phase 12: Docker & Containerization for Production
- Phase 13: CI/CD Pipelines & Cloud Deployment

---

### 🚀 Key Functional Modules & User Workflows:

#### 1. Dual-Portal Entry & Role Isolation
- Clean entry point clearly separating the Learner Portal from the Coordinator Admin Portal, ensuring members cannot accidentally access coordinator tools without explicit credentials.

#### 2. Visual 13-Phase Syllabus Roadmap
- Comprehensive visual pipeline showing all phases, estimated study times, subtopic checklists, and verified evidence scores (0–100%).
- Real-time debounced search and category filtering across Python, FastAPI, Postgres, AI, RAG, and DevOps modules.

#### 3. Daily Learning Tasks & Reflection Engine
- Daily check-in form capturing minutes studied, specific topics learned, confidence rating (1–5 ⭐), and specific concepts confused about.
- Low-confidence ratings automatically trigger peer help suggestions to prevent learning debt.

#### 4. Assignment Hub & Multi-Criteria Code Evaluation Studio
- Coding challenges requiring verified GitHub Pull Requests.
- Standardized 4-pillar grading rubric:
  1. Code Quality & Formatting
  2. Architecture & Conceptual Understanding
  3. Automated Tests & Edge Cases
  4. Documentation & OpenAPI Spec Alignment

#### 5. GitHub Integration & Conventional Commit Quality Engine
- Live stream of recent commits with semantic convention parsing (`feat`, `fix`, `docs`, `test`, `refactor`).
- Interactive commit simulator scoring message quality (0–100%) to train professional git hygiene.
- Pull Request collaboration board showing code volume, review status, and group leaderboard.

#### 6. Collaborative Peer Help & Growth Hub
- Community board displaying classmates requesting help on specific topics.
- One-click "Offer to Pair & Help" action enabling classmates to volunteer as peer tutors and pair-program.

#### 7. Live Peer Pairing Studio (Real-Time Collaborative Room)
- Collaborative workspace featuring a shared real-time code scratchpad, live chat with syntax-highlighted code sharing, simulated audio/video communication, and a celebratory "Mark Concept as Resolved" action that awards mastery points to both peers.

#### 8. Full-Page Learner Analytics Hub
- Dedicated personal profile and analytics page showing weekly study time charts, 14-day consistency calendar, topic mastery breakdown, and daily reflection history.

#### 9. Coordinator Command Center & Individual Diagnostic Console
- Complete CRUD controls for syllabus modules, assignments, and learner permissions.
- Individual Diagnostic Drawer: Deep-dive into any specific student's progress, automatically flagging low-confidence topics and generating personalized coaching action plans with assigned peer mentors.
```
